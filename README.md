# OBDC-Comparison
Compares four Bayesian dose-finding designs (Comb-BOIN12, EffTox, COMIC, uTPI-Comb) for two-agent Phase I/II oncology trials. Includes a command-line report (execution.R) and a live Shiny app (https://22c7ba-damitri-kundu.shinyapps.io/OBDC-Compare-App/) to explore scenarios and compare operating characteristics side by side.
